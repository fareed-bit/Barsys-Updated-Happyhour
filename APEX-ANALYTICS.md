# Apex analytics installation — local review branch

Not published. All 20 public HTML pages load the shared consent controller
from Apex. Apex supplies the controller and existing ingest endpoint. Collection
is off until the visitor chooses to allow it; the choice is tab/site scoped,
revocable, and respects Global Privacy Control. No form field values are sent.
The notice describes these controls and preserves the existing service list.

Controller behavior tests live in Apex: scripts/tests/analytics_consent.cjs.
Existing GTM and other services are unchanged by this additional opt-in control.
Browser events are not confirmed inquiries or revenue. Server-side inquiry
receipts and CRM attribution require a separate integration.

Review the source diff before publishing this branch. No real visitor events
have been generated by the local verification.
